# Pacemaker 관리자 MCP 설치 안내 (Claude 데스크톱)

Claude에게 말로 시켜서 홈 화면 메인 배너를 확인하고 수정하는 기능입니다.
터미널이나 개발 도구는 필요 없고, 파일 하나를 설치하면 됩니다.

## 준비물

- Claude 데스크톱 앱 (Mac 또는 Windows)
- Pacemaker **관리자 계정** (일반 계정은 로그인은 되지만 서버가 사용을 거부합니다)
- 담당자에게 받은 확장 파일 `pacemaker-admin-<버전>.mcpb`

## 설치 (처음 한 번)

1. 받은 `.mcpb` 파일을 **더블클릭**합니다. Claude 앱에 설치 창이 열립니다.
2. 이름이 **Pacemaker Admin**인지 확인하고 **Install(설치)** 을 누릅니다.
3. 창이 안 열리면 Claude 앱의 설정 → 확장 프로그램 → 고급 → 확장 설치에서 파일을 고르세요.

## 로그인 (처음 한 번)

1. Claude에서 **새 채팅**을 엽니다.
2. 이렇게 말합니다: **"Pacemaker 메인 배너 목록 보여줘"**
3. 브라우저 창이 열리면 Pacemaker **관리자 계정**으로 로그인합니다.
4. 동의 화면에서 `PACE-333 Pacemaker MCP (Production)`이 맞는지 확인하고 **Allow** 를 누릅니다.
5. "Signed in" 화면이 뜨면 창을 닫고, Claude에게 같은 요청을 다시 합니다. 배너 목록이 나오면 성공입니다.

로그인은 컴퓨터에 안전하게 저장되어, 다음부터는 다시 로그인하지 않아도 됩니다.

## 사용 방법

- 조회: "첫 번째 배너 자세히 보여줘"
- 수정: "두 번째 배너 설명을 ○○○으로 바꿔줘"
  1. Claude가 **변경 전후와 미리보기 링크**를 보여 줍니다. 이때는 아무것도 바뀌지 않습니다.
  2. 미리보기 링크를 열어 모양을 확인합니다. 링크는 10분 안에 열어야 하고, 관리자로 로그인된 브라우저에서만 열립니다.
  3. 괜찮으면 "적용해줘"라고 말합니다. **이때부터 실제 홈 화면이 바뀝니다.**
- 되돌리기: "방금 변경을 원래대로 되돌려줘"라고 하면 직전 값으로 다시 제안합니다. 같은 방식으로 확인한 뒤 적용합니다.
- 모든 변경은 누가, 무엇을, 언제 바꿨는지 기록으로 남습니다.

수정할 수 있는 것은 제목, 설명, 버튼 이름, 버튼 링크(사이트 안 경로), 공개 여부입니다. 이미지, 순서 변경, 추가·삭제는 아직 안 됩니다.

## 로그아웃

더 이상 쓰지 않거나 컴퓨터를 다른 사람과 쓸 때는 Claude에게 **"Pacemaker sign out 해줘"** 라고 하세요. 저장된 로그인이 지워지고 권한이 취소됩니다.

## 문제가 생겼을 때

| 증상                                       | 해결                                                                                                                                                                                                                        |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "관리자 계정으로 로그인하세요 (Forbidden)" | 관리자 계정이 아닙니다. 로그아웃(위 방법) 후 관리자 계정으로 다시 로그인                                                                                                                                                    |
| 로그인 창이 안 열림                        | Claude 답변에 나온 주소를 브라우저에 직접 붙여넣어 여세요                                                                                                                                                                   |
| 로그인 후 아무 일도 없음                   | 브라우저에서 관리자가 아닌 계정으로 이미 로그인돼 있을 수 있습니다. 시크릿 창에서 열어 관리자 계정으로 로그인해 보세요                                                                                                      |
| "port 53134 is already in use" 메시지      | 다른 프로그램(다른 앱에서 로그인을 기다리는 Pacemaker MCP 등)이 로그인 통로를 쓰고 있습니다. 5분쯤 기다렸다가 다시 하거나, Claude를 완전히 종료한 뒤 다시 열어 보세요. 그래도 안 되면 컴퓨터를 재시작하거나 담당자에게 문의 |
| 미리보기 링크가 안 보임                    | 담당자에게 문의하세요 (서버 설정 문제)                                                                                                                                                                                      |
| 확장 목록에 Pacemaker Admin이 없음         | 설치가 안 된 것입니다. 파일을 다시 더블클릭하거나 회사 Claude 설정에서 확장 설치가 막혀 있는지 담당자에게 확인                                                                                                              |
| 새 기능이 안 보임                          | 담당자가 보낸 새 버전 파일을 같은 방법으로 설치하세요                                                                                                                                                                       |

## 담당자용

- 확장 파일은 `mcp/`에서 `npm run build:mcpb`로 만듭니다. 방법과 배포 절차는 `mcp/README.md`의 "Claude Desktop extension" 절을 보세요.
- 파일을 전달할 때는 빌드 출력의 sha256 값과 변경 내용을 함께 보내세요.
- Windows에서의 설치와, 새 파일을 이전 것 위에 설치할 때의 동작은 아직 확인하지 못했습니다.
